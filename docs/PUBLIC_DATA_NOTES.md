## 使用原則

1. 只使用公開來源可查證的資訊。
2. 不放入未授權選手個資。
3. 不引用或混用「中華民國飛鏢總會」網站資料，避免與本案總會混淆。
4. 對於尚未取得總會正式核定的排名、會員、組織與附件資料，標示為待更新，不建立未經核准的內容。
5. 「查看來源或對應文件」連結設定為開新分頁，不會取代原本頁面。
6. Logo 與封面圖應使用總會提供或確認授權的版本。

## 待總會確認

- 正式公告文案與附件版本。
- 各賽事規程、報名表、賽果與成績表。
- 正式排名資料與積分規則。
- 組織架構、聯絡資訊、章程與隱私權政策。
- 代表隊、選手與活動照片之肖像權與授權範圍。
