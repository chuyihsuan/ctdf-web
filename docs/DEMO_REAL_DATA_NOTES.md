# Demo 實際資料使用說明

本文件說明目前靜態 demo 中使用的公開資料來源與使用原則，方便總會審閱時判斷哪些內容可保留、修正或替換為正式資料。

## 1. 使用原則

- Demo 可放入公開資料，讓網站樣貌更接近正式官網。
- 所有公開資料僅作靜態展示與版型審閱。
- 正式上架前，仍需總會確認文字、賽事規程、代表隊資料、排名成績與附件版本。
- 不放入正式會員個資、密碼、API key、網域密碼或未授權個人資料。
- 不直接轉載新聞全文或未授權照片，只使用摘要、標題式說明與外部來源連結。
- 涉及青少年選手姓名、照片、成績時，正式上架前需特別確認公開授權。

## 4. 建議總會審閱重點

1. 首頁的真實資料呈現是否比純示意資料更容易理解網站價值。
2. 哪些公開資料可正式納入官網。
3. 哪些內容需改成總會正式公告文字。
4. 哪些賽事、文件、照片或成績需由總會提供原始檔。
5. 是否需要先隱藏選手姓名或青少年成績，等授權確認後再公開。
